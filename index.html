5. Relación con el cálculo vectorial

Función vectorial base:
r(t) = ⟨20 + 10t, 2 + 0.2t²⟩
Dominio: 0 ≤ t ≤ 8
Velocidad: v(t) = ⟨10, 0.4t⟩
Magnitud: |v(t)| = √(100 + 0.16t²)
Aceleración: a(t) = ⟨0, 0.4⟩

Extensión del simulador:
rₛ(t) = ⟨20 + 10t + C, 2 + 0.2t² + M⟩
C: carga adicional de CPU.
M: memoria adicional en GB.

Entre cambios de programas, C y M son constantes y la velocidad coincide con la de la función base. En el instante en que cambia un programa, hay un salto que no describe esa derivada. CPU y RAM tienen unidades diferentes.
